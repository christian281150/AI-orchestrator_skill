# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique work and not people, and keep discussions on-topic and
evidence-based. Harassment of any kind is not tolerated.

**Reporting:** contact the maintainer privately through GitHub (profile
[@christian281150](https://github.com/christian281150)) or use the repository's private reporting channel.
Reports are handled confidentially. Maintainers may remove comments, issues or contributions that violate
this code, and may block repeat offenders.
